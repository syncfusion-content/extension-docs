# Overview of Syncfusion® Document SDK for Visual Studio

The Syncfusion® Document SDK for Visual Studio is used to integrate Syncfusion® Document processing components into applications by configuring the Syncfusion® NuGet packages and themes.

The Syncfusion® Document SDK provides the following add-ins in Visual Studio:

[Template Studio](template-studio): Creates Syncfusion® Blazor applications with required configuration for development with Syncfusion® Document SDK components.

[Code Generator](code-generator): Adds Syncfusion® Document SDK component code into the Razor file of a Blazor application at the required place.

[Sample Creator](sample-creator): Creates Syncfusion® ASP.NET Core or MVC application with the sample code of required Syncfusion® Document SDK controls and features.

I> The latest Syncfusion® Document SDK extension supports Visual Studio 2022 and later with .NET 10.0, .NET 9.0, and .NET 8.0. Refer to [Download and Installation](download-and-installation) for prerequisites and setup.
