# Overview of PDF Viewer SDK Extension for Visual Studio Code

N> The Syncfusion® PDF Viewer SDK Extension for Visual Studio Code is available from Essential Studio® 2026 Volume 1 (v33.1.44). Refer to the [Download and Installation](download-and-installation) topic for prerequisites.

The [Syncfusion® PDF Viewer SDK Extension for Visual Studio Code](https://marketplace.visualstudio.com/items?itemName=SyncfusionInc.PDF-Viewer-SDK-VSCode-Extensions) simplifies integration by configuring the required Syncfusion® PDF Viewer SDK NuGet packages.

The Syncfusion® PDF Viewer SDK Extension provides the following support in Visual Studio Code:

[Project Template](create-project): Creates Syncfusion® PDF Viewer SDK applications with the required configuration for development with the Syncfusion® PDF Viewer SDK component.

[Blazor Code Snippet](code-snippet#configure-blazor-application-with-syncfusion): Adds a Syncfusion® PDF Viewer SDK component with various features to the Blazor Application's Razor code editor.

[.NET MAUI Code Snippet](code-snippet#configure-net-maui-application-with-syncfusion): Adds a Syncfusion® PDF Viewer SDK component with multiple features into the .NET MAUI Application's XAML code editor.
