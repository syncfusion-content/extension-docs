# Syncfusion® JSON Visualizer - Download and Installation Guide

Syncfusion® publishes the JSON Visualizer Extension in [Visual Studio Code marketplace](https://marketplace.visualstudio.com/items?itemName=SyncfusionInc.JSON-Visualizer-VSCode-Extensions). You can either install it from Visual Studio Code or download and install it from the Visual Studio Code marketplace.

## Prerequisites

Before getting started, make sure your environment meets the following requirements:

* [Visual Studio Code](https://code.visualstudio.com/download)

 > The minimum version of the Visual Studio Code is 1.73.0 to use the JSON Visualizer Extension.


## Install through the Visual Studio Code

The following steps explain how to install the JSON Visualizer extensions from Visual Studio Code Extensions.

1. Open Visual Studio Code.

2. Go to **View > Extensions**.

3. Type **Syncfusion - JSON Visualizer** in the search box.

     ![Extension](Images/ExtensionsView.png)

4. Click the Install button on the **"Syncfusion® JSON Visualizer"** extension.

5. After the installation completes, restart Visual Studio Code if prompted.


## Install from the Visual Studio Code Marketplace

The following steps explain how to download JSON Visualizer extension from the Visual Studio Code Marketplace and install them.

1. Visit the [JSON Visualizer Extension MarketPlace page](https://marketplace.visualstudio.com/items?itemName=SyncfusionInc.JSON-Visualizer-VSCode-Extensions).

2. Click Install from Visual Studio Code Marketplace. The browser opens the popup with the information like **“Open Visual Studio Code”**. Click Open Visual Studio Code, then [JSON Visualizer Extension](https://marketplace.visualstudio.com/items?itemName=SyncfusionInc.JSON-Visualizer-VSCode-Extensions) will open in Visual Studio Code.

3. Click the Install button in the **"Syncfusion® JSON Visualizer"** extension.

4. After the installation, restart Visual Studio Code when suggested.
