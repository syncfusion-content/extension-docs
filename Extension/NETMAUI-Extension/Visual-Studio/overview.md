# Overview of .NET MAUI Extension for Visual Studio

The Syncfusion<sup>®</sup> .NET MAUI Extension for Visual Studio simplifies the use of Syncfusion<sup>®</sup> .NET MAUI components by automatically configuring the required NuGet packages. It streamlines development by giving developers easy access to powerful features, saving both time and effort.

[Visual Studio Extension](https://marketplace.visualstudio.com/items?itemName=SyncfusionInc.MAUIVSExtension)

The Syncfusion<sup>®</sup> .NET MAUI extensions provide the following add-ins in Visual Studio:

* [Project Template](template-studio.md): Creates Syncfusion<sup>®</sup> .NET MAUI applications with the required Syncfusion<sup>®</sup> components and configurations for development.

* [Toolbox Control](Toolbox-Control.md): Adds Syncfusion<sup>®</sup> .NET MAUI components to your XAML file via the Visual Studio Toolbox and automatically configures the required NuGet packages and namespaces.

* [Essential<sup>®</sup> UI Kit](Essential-UI-Kit.md): Provides ready-to-use XAML templates to quickly build cross-platform user interfaces for your .NET MAUI application.

* [Notifications](Syncfusion-Notifications.md): Displays notifications about trial application usage, newer Syncfusion<sup>®</sup> NuGet package versions, newer Essential Studio<sup>®</sup> builds, and invalid license keys.
