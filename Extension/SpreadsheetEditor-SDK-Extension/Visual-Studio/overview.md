# Overview of Syncfusion® Spreadsheet Editor SDK Extension

The Syncfusion® Spreadsheet Editor SDK Extension for Visual Studio seamlessly integrates Spreadsheet component into Blazor, WPF and Windows Forms applications. By utilizing Syncfusion’s NuGet packages and customizable themes, developers can effortlessly enable robust Excel document viewing, editing, and printing capabilities. Enhance your application’s document management with a streamlined, efficient, and versatile solution.

The Syncfusion® Spreadsheet Editor SDK extension provides the following add-ins in Visual Studio:

[Template-Studio](template-studio.md): Creates Syncfusion® applications based on platform (Blazor, WPF, Windows Forms) with the required configuration for development with the Syncfusion® Spreadsheet Editor SDK component.

[Code Generator](code-generator.md): Adds Syncfusion® Spreadsheet Editor SDK component code in the razor file of a Blazor Application at the required place.

[Item Template](item-template.md): Adds a predefined Syncfusion® Spreadsheet Editor SDK control and the required assemblies in WinForms and WPF Applications.

[Sample Creator](sample-creator.md): Creates a Syncfusion® ASP.NET Core or MVC application with the sample code of the required Syncfusion® Spreadsheet Editor SDK control and features.

[Reference Manager](Add-References.md): Adds the required Syncfusion® Spreadsheet Editor SDK assembly reference to WPF and Windows Forms projects.
